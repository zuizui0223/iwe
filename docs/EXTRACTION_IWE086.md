## Source eligibility

## Biological chain visible before quantitative extraction

The published abstract divides the flowering season into two biologically distinct periods:

- an earlier period with a relatively high bee:flower ratio and high seeds per ovary;
- a later period with lower bee:flower ratio and lower seed set.

The source also reports that individual pollinator visitation rate is strongly associated with seed set in the later, pollinator-limited period.

Thus the study contains both seasonal pollinator availability and final female reproductive output.

## Critical estimand distinction frozen before full numerical recovery

IWE086 separates two source relations:

1. **temporal partner availability** — seasonal bee:flower ratio or an equivalent source-defined bee-availability measure through flowering time;
2. **realized individual interaction intensity** — visitation rate to a focal plant/flower.

Only the first can identify IWE H1's plant–partner temporal-matching estimand.

A correlation between individual visitation rate and seed set within one seasonal period is biologically useful pollination-service evidence, but it is not automatically a phenological-synchrony effect because among-plant attractiveness can generate visitation differences without differences in temporal matching.

Therefore IWE086 may enter strict H1 only if the source permits a quantitative relation of the form:

```
seasonal bee availability at plant flowering
-> final seed set
```

across enough independent plant/time units to estimate sampling uncertainty.

## Preferred quantitative routes

In descending order:

1. recover date/time-bin bee:flower availability together with seed set for the same independently defined flowering units and compute a registered correlation or model coefficient;
2. recover individual plant flowering timing, map each plant prospectively onto the independently measured bee-availability curve, and relate that availability-at-flowering score to seeds per ovary;
3. recover a source model coefficient that directly estimates the temporal bee-availability effect on seed set with an SE/covariance.

If the source supplies only two broad seasonal periods, the contrast is retained as timing context unless a source-reported uncertainty for the period contrast supports a prospectively registered effect family. The many flowers/seeds within a period cannot be treated as independent temporal-matching replicates.

## Prohibited shortcuts

IWE086 will not:

- relabel flowering date alone as synchrony;
- use individual visitation rate alone as the primary timing exposure;
- infer an effect magnitude from the abstract phrase “very strong correlation”;
- derive an `r` from a P value without a source sample size and declared model;
- count flowers or ovaries as independent timing units when bee availability is shared at the seasonal-period level;
- choose the earlier or later period because its result better fits H1.
