# Cirsium–Rhinocyllus public completion audit

Date: 2026-09-25  
Candidate: `ANT002_CIRSIUM_RHINOCYLLUS`  
Decision: keep P2 blocked, but mark **public search exhausted**

## What the public programme actually contains

Russell & Louda (2004) is a genuine synchrony source. Across Nebraska Sand Hills sites and years it directly quantified adult *Rhinocyllus conicus* activity, *Cirsium canescens* flower-head development and a source-defined measure of their phenological synchrony. Synchrony explains variation in weevil egg load.

Rose, Louda & Rees (2005) is a genuine final-fitness source from the long-term Platte-thistle programme. Its individual-level demographic data include final seed set and *Rhinocyllus* egg load. The fitted seed-set model is explicitly a function of plant size, weevil egg load and native floral damage.

Older programme syntheses also report severe viable-seed losses in flower heads attacked by *Rhinocyllus*.

## Why this still does not close antagonist #2

The public sources expose:

1. a source-defined synchrony → egg-load relation; and
2. an egg-load/damage → final-seed relation.

They do not expose a table in which the **same independent site-year or plant unit** carries both the synchrony exposure and final viable-seed outcome with variance suitable for the frozen SMD contrast.

The public search also did not recover an Ecological Archives, Dryad or institutional dataset containing that join.

Attack/no-attack viable-seed comparisons are not substitutes. They answer the cost of attack, not the effect of greater phenological synchrony.

- use attack presence/absence as synchrony;

- keep repeating generic web searches for the same public papers.

This candidate advances only if the underlying same-unit data are recovered.
