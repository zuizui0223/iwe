# Claim ceiling

IWE tests empirical hypotheses about phenological synchrony and plant reproductive performance.

## Primary claim if H1 is supported

> Across the admitted direct literature, the reproductive consequence of phenological synchrony differs among interaction types.

## Additional claim if H2 is evaluable and supported

> In the admitted mixed pollinating-seed-predator evidence, greater synchrony is not uniformly associated with greater plant reproductive performance.

## Claims not licensed by IWE alone

IWE does not infer that:

- synchrony causally determines fitness in all systems;
- intermediate synchrony is universally optimal;
- specialist systems are universally more climate-sensitive;
- occurrence-derived potential overlap equals realized interaction overlap;
- a measured timing pattern identifies a particular evolutionary architecture;
- modularity or trait differentiation evolved because of timing;
- any SCH/BALANCE/SLK/BITA/PAYOFF quantity has been measured.

## Valid endpoints

A null interaction-type contrast, opposite-to-predicted class effect, insufficient mixed-system support for curvature, or unresolved variance/dependence structure is a valid scientific endpoint. The project must not change screening, effect orientation, class definitions, or outcome hierarchy after seeing the preferred result.
