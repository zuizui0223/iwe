# IWE × chocho — non-promoting space–time bridge (pilot v0.1)

## What is implemented

This optional bridge compares IWE's **50 replication candidate records** against
chocho's **239-species frozen butterfly resource-geography metrics** by **exact
full binomial only**. The current cross-repository audit found one overlap:
*Anthocharis cardamines* in the IWE Cardamine antagonist completion candidate.

At the pinned chocho snapshot, this butterfly has:

- 162 WGSRPD3 resource units from native host geography;
- 272 contemporary units when introduced ranges of known hosts are retained;
- 110 added units (a 67.9% increase on 162), over **all 11 resolved hosts**.

**These are species-wide host-union geography metrics, not a measured spatial
response of *Cardamine pratensis* or a record of host use at any one site.**
IWE's *Cardamine pratensis* × *A. cardamines* pair is not automatically confirmed
by the geographic summary. An exact species-level pair can be corroborated only
against the external chocho-generated HOSTS sidecar.

### Reproduce the crosswalk

Check out chocho commit df6f920a37c7e86a878d9f6375bb4454128b5d66
alongside IWE and, from the IWE root, run:

~~~
python scripts/build_chocho_bridge.py \
  --chocho-metrics ../chocho/data/frozen/figure_sources/anthropogenic_species_metrics.csv \
  --out-dir outputs/chocho_bridge
~~~

The CLI checks the exact chocho source file's Git blob SHA-1,
9f83d2d9ac8e46f1cfd4ded572c7a023273503dd. It records SHA-256s of both
input files and generates:

- candidate_resource_crosswalk.csv
- bridge_status.json

To smoke-test without the separate checkout, a **single-species fixture**
is available at examples/chocho_pilot_species_metrics.csv:

~~~
python scripts/build_chocho_bridge.py \
  --chocho-metrics examples/chocho_pilot_species_metrics.csv \
  --expected-chocho-blob none \
  --out-dir outputs/chocho_bridge_fixture
~~~

This fixture is *not* the 239-species external-input validation. An unpinned
file remains labeled unpinned in the status output.

### Optional host-pair validation

The independently built chocho sidecar
(insect_host_accepted.csv from build_wcvp_hosts_contemporary_sidecar.R)
provides insect_species and accepted_name. Add:

~~~
  --hosts-sidecar /path/to/insect_host_accepted.csv
~~~

This updates the host_pair_status from not_checked to
confirmed_in_hosts_sidecar **only for exact pairs**. A pair absent from a
supplied sidecar is not evidence of ecological absence; taxonomic matching
and source coverage are incomplete.

## An explicit temporal screening interface — no fabricated field evidence

Optional --seasonal-windows CSV columns:

| key | meaning |
| --- | --- |
| candidate_id, host_taxon | Exact IWE candidate identity and focal plant species |
| wgsrpd3_unit, year | Same local region/year for both measured windows |
| range_origin | sourced native or introduced status of the focal plant in that region |
| host_range_source | provenance for the region × plant origin label |
| host_window_source | provenance for directly observed host phenophase |
| partner_window_source | provenance for independent adult activity (NOT eggs or damage) |
| host_window_basis | exactly observed_host_phenophase |
| partner_window_basis | exactly independent_adult_activity |
| host_start_doy, host_end_doy | observed half-open annual day-of-year interval |
| partner_start_doy, partner_end_doy | independently measured half-open adult interval |

CLI usage when BOTH a verified host-pair sidecar and authentic annual regional
windows exist:

~~~
python scripts/build_chocho_bridge.py \
  --chocho-metrics ../chocho/data/frozen/figure_sources/anthropogenic_species_metrics.csv \
  --hosts-sidecar /path/to/insect_host_accepted.csv \
  --seasonal-windows /path/to/independent_measured_windows.csv \
  --out-dir outputs/chocho_bridge
~~~

The additional potential_phenophase_overlap.csv reports interval Jaccard
(intersection / union) and intersection / host-window length. It is **Tier-C-like
proxy-only screening**, never an admitted Tier A synchrony–fitness effect.
Genuine no-overlap measured pairs can score zero; **missing adult dates, missing
years, absent regions or GBIF non-observations are never filled as zeros**.

No such original-data windows have been supplied or generated by this pilot.
The critical 2012–2014 Dibbinsdale female A. cardamines flight-event dates
(or independently reported exact year-specific q10/q90 cutoffs) remain missing
under the existing IWE Cardamine contract. A contemporary map or synthetic
window must not bypass that gate. The exact IWE Cardamine q10/q90
first-flowering design remains authoritative for strict H1.

## Testable biological hypothesis for a future *independent* analysis

**HST1:** After accounting for sampling effort, host identity, phenophase
type, climate, and region/year dependence, regions newly supplied with
larval-host resources vary in realized butterfly–host use partly because
host-phenophase timing and adult/larval activity are mismatched.

- Geographic support must be reconstructed at the **individual host × region**
  level, not inferred from the per-butterfly union metric.
- Larval feeding phenophases may differ from adult oviposition substrates;
  an adult flight interval is a proxy whose suitability must be justified
  per natural-history system.
- Do not use HOSTS recording Location alone to assert year-specific
  host use, invasion timing, oviposition or population growth.
- Compare sourced native/introduced regions with explicit effort and
  region/climate sensitivity. Stratify by species/host; do not treat
  pseudo-replicated region records as independent effect-size clusters.
- Retain genuine zero/null outcomes; lack of a robust temporal effect is
  a valid result.

**IWE remains the plant-fitness/meta-analysis home; chocho remains the
butterfly geographic-opportunity manuscript. Neither frozen manuscript,
adjudication registry, nor strict-H1 effect set is modified by this bridge.**
